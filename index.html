Apuração e projeção por UF

Como a projeção é calculada

Para cada UF (e para o exterior), a página divide o eleitorado das seções já totalizadas pelo eleitorado total da UF. Os votos de cada candidato são divididos por essa fração, como se as seções restantes tivessem o mesmo comparecimento e a mesma divisão de votos das já apuradas. A soma das 28 projeções dá o resultado nacional.

A ordem de apuração dentro de cada UF não é aleatória: capitais e interior chegam em ritmos diferentes. A projeção corrige as diferenças entre estados, mas não dentro de cada estado.

UFs sem apuração ou com menos de 5% do eleitorado apurado são tratadas como não apuradas: entram na projeção com o resultado do 1º turno na UF, dividido entre os dois finalistas, aplicado aos votos válidos do 1º turno.

Esta é uma estimativa matemática, não um resultado. O resultado oficial é o divulgado pelo TSE em resultados.tse.jus.br.
